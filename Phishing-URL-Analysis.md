Phishing URL Analysis

Project Overview

This beginner-friendly cybersecurity project explains how to identify suspicious URLs and recognize common phishing indicators.

Objective

To understand how attackers use fake or misleading URLs to trick users into sharing passwords or sensitive information.

Tools Used

- GitHub
- Web browser
- Basic cybersecurity knowledge

Common Phishing Indicators

1. Misspelled domain: A website address uses a name similar to a legitimate brand.
2. Suspicious subdomain: A trusted brand name appears inside an unrelated domain.
3. Unusual URL: The address contains misleading words or unexpected characters.
4. Unexpected login page: A link asks for passwords or sensitive information unexpectedly.
5. HTTP connection: The website uses HTTP instead of HTTPS. Note: HTTPS alone does not prove a website is safe.

Example Analysis

Example URL: "http://secure-login-example.invalid"

Observations:

- The URL uses HTTP.
- The domain name suggests a login page.
- The ".invalid" domain is reserved for invalid examples and is not a real public website.

Verdict: Do not treat this example as a real phishing website. It is a demonstration of suspicious URL analysis.

Recommended Safety Actions

- Do not click suspicious links.
- Never enter passwords on unverified websites.
- Verify the domain through the organization's official website.
- Report suspicious emails to the security team.
- If credentials were entered, change the password using the official website and notify the security team.

Conclusion

Analyzing URLs is an important first step in phishing detection. A SOC Analyst combines URL indicators with other evidence before deciding whether a link is malicious.
